## 1. 폴더 놓기 (2분)

1. 받은 ZIP을 `C:\Users\sulla\WorkSpaces\ai-practice-handbooks\sonovman_blog\` 에 풉니다.
2. 결과가 아래처럼 되면 정상입니다.

```
sonovman_blog\
├── Undestanding_MAGA\     ← 원고 보관용 (올리지 않음)
└── sonovman-blog\         ← ★ 이것이 새 저장소
    ├── index.html
    ├── catalog.js
    ├── style.css
    ├── .nojekyll          (숨김 파일처럼 안 보일 수 있음 — 정상)
    ├── README.md
    ├── 새-연재-추가하기.md
    └── understanding-maga\
```

> 원고 폴더(`Undestanding_MAGA`)는 저장소 **바깥**에 두었습니다. 편집 기록·원본 자료가 공개되지 않게 하기 위해서입니다.
> `sonovman-blog` 폴더를 `ai-practice-handbooks` 클론 **안에 넣지 마세요.** 저장소 안에 저장소가 생겨 꼬입니다.

## 2. 내 컴퓨터에서 미리 보기 (선택, 1분)

`sonovman-blog\understanding-maga\01\index.html` 을 더블클릭하면 브라우저에서 열립니다.
(홈의 연재 목록과 '원고 복사' 버튼은 인터넷에 올린 뒤에 더 확실하게 동작합니다.)

## 3. GitHub Desktop으로 새 저장소 만들기 (3분)

1. GitHub Desktop 실행 → 메뉴 **File → Add local repository…**
2. **Choose…** 를 눌러 `...\sonovman_blog\sonovman-blog` 폴더 선택
3. "This directory does not appear to be a Git repository" 문구 아래 **create a repository** 링크 클릭
4. 나오는 창에서
   - Name: `sonovman-blog` (그대로)
   - Initialize this repository with a README: **체크하지 않음** (이미 있음)
   - Git ignore: **None**, License: **None**
   - **Create repository**
5. 왼쪽에 파일 목록이 보이면 첫 기록(커밋)이 만들어진 것입니다.

## 4. GitHub에 올리기 — Publish (2분)

1. 위쪽 파란 버튼 **Publish repository** 클릭
2. Name: `sonovman-blog`
3. **"Keep this code private" 체크를 해제** ← 중요
   무료 계정에서 웹사이트(Pages)로 보이려면 **공개(Public)** 저장소여야 합니다.
4. **Publish repository**

## 5. 웹사이트로 켜기 — Pages (2분)

1. 브라우저에서 https://github.com/sonovman/sonovman-blog 열기
2. 위쪽 **Settings** → 왼쪽 **Pages**
3. Source: **Deploy from a branch**
4. Branch: **main**, 폴더: **/(root)** → **Save**
5. 1~3분 뒤 https://sonovman.github.io/sonovman-blog/ 접속 (안 보이면 Ctrl+F5)

## 6. 확인할 것 (3분)

- [ ] 홈에 연재 카드가 1개 보인다
- [ ] 연재 목차에 1부·2부·3부와 카드 8개가 보인다
- [ ] 각 편 아래 '이전 편 / 목차 / 다음 편'으로 이동된다
- [ ] 본문의 `[1]` 을 누르면 아래 「근거와 더 읽을 자료」로 내려간다 (목록을 펼쳐야 보임)
- [ ] '이 편 원고 복사' 버튼을 누르면 "복사했습니다" 알림이 뜬다
- [ ] 휴대폰으로 열어도 글이 옆으로 넘치지 않는다

## 7. 고치고 다시 올릴 때

1. 폴더 안 파일을 고치고 저장
2. GitHub Desktop: **Fetch origin** → (있으면) **Pull origin**
3. 왼쪽 아래 Summary에 메모 한 줄 → **Commit to main** → **Push origin**
4. 1~3분 뒤 새로고침

새 편·새 연재 추가는 저장소 안의 `새-연재-추가하기.md` 를 보세요.

## 자주 막히는 곳

| 증상 | 해결 |
|---|---|
| 주소를 열면 404 | Pages 켠 뒤 1~3분 기다리기. Settings → Pages에 초록색 "Your site is live" 가 떴는지 확인 |
| 홈에 카드가 안 보임 | `catalog.js` 묶음 끝 쉼표(,)나 따옴표가 빠졌는지 확인 |
| 디자인이 깨져 보임 | Ctrl+F5 (예전 파일이 브라우저에 남아 있는 경우) |
| Publish 뒤 Pages 메뉴에서 유료 안내가 나옴 | 저장소가 Private로 올라간 것. Settings → General 맨 아래 **Change visibility → Public** |
| 웹 화면에서 끌어다 올렸더니 일부가 빠짐 | 웹 업로드는 점(.)으로 시작하는 파일(`.nojekyll`)을 건너뜁니다. GitHub Desktop을 쓰세요 |
